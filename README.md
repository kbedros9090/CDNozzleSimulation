# CD Nozzle Simulation

# Objective 
This project's purpose is to design and simulate a sea-level de Laval nozzle. The nozzle is developed using SolidWorks for geometry and ANSYS for integrated CFD/FEA analysis. Numerical results are compared with theoretical predictions. Film and regenerative cooling strategies are used to manage thermal loads. The goal is to evaluate the nozzle performance in terms of velocity and Mach number distribution. Additionally, the project ensures structural integrity reviewing deformation, stress, and temperature of the nozzle walls. 

**WARNING** This document is intended for student learning purposes only. They are meant to help understand ANSYS, CFD, and FEA simulations. This design does not represent a working or safe propulsion system and should not be used for any practical applications.
